為什麼要在本機做

市面上的逐字稿服務幾乎都是上傳制：你的會議錄音送到別人的伺服器，轉完再傳回來。對一般閒聊沒差，但如果那場會議談的是薪資、併購、客戶名單或未上市的產品規格，這個動作本身就是問題——很多公司的資安規範根本不允許。

MeetingNotes Studio 把辨識放在你的 Mac 上跑，用 Apple Silicon 的算力，依語言自動選用 Breeze-ASR-26 或 Whisper MLX。音檔和辨識過程都不出這台機器。只有在你按下「AI 摘要」而且選了線上模型時，逐字稿的文字才會送出去——這一步是你自己按的，不按就完全離線。

它做什麼

離線辨識，聽得懂台語

依語言自動選用 Breeze-ASR-26 或 Whisper MLX。Breeze 是針對台灣語境訓練的模型，台語和中英夾雜的會議都吃得下。

錄音、匯入、YouTube 都能轉

可以直接錄現場，也可以匯入 M4A、MP3、MP4 等常見音訊與影片檔；在瀏覽器播 YouTube 時能擷取系統音訊做聽寫。

逐字稿帶時間標記

每一段都對得回音檔的時間點，點文字就跳到那一秒。校稿時不用來回猜位置。

AI 摘要整理重點與待辦

確認逐字稿之後再摘要，整理出重點、決策與待辦事項。模型可以選本機的，也可以用自備 API Key 的線上模型。

匯出成能直接用的檔案

Word（DOCX）、PDF、純文字，以及可匯入 Google Docs 的格式。不是只能在 App 裡看。

權限只要最低限度

錄音需要麥克風權限；YouTube 聽寫需要你主動開啟螢幕與系統音訊擷取。兩者都不會在背景自己啟動。

常見問題

真的支援台語嗎？

是。台語的辨識走 Breeze-ASR-26，這是針對台灣語境訓練的模型，對台語以及中英台夾雜的會議表現比通用模型好。這也是多數線上逐字稿服務目前處理不好的部分。

音檔會被上傳嗎？

不會。錄音與語音辨識都在你的 Mac 上完成。唯一會離開電腦的情況是你按下「AI 摘要」並且選擇線上模型，這時送出的是逐字稿文字，不是音檔；選本機模型則整個流程都不連網。

需要網路嗎？需要 API Key 嗎？

轉逐字稿不需要網路，也不需要任何帳號。只有想用線上的 AI 模型做摘要時才需要自備 API Key；用本機模型就不用。

哪些 Mac 可以跑？

Apple 晶片的 Mac（M 系列）。離線辨識吃的是 Apple Silicon 的機器學習算力，Intel Mac 不在支援範圍。

可以轉線上課程或 YouTube 影片嗎？

可以。在預設瀏覽器播放時擷取系統音訊即可聽寫。也可以先把影片檔匯入，App 支援 MP4 等常見格式。

逐字稿可以匯出到哪裡？

Word（DOCX）、PDF、純文字，以及可匯入 Google Docs 的格式。摘要與逐字稿都能一起帶走。
